# 🏆 Unit 6 — Ranking Test

**NOF Maths Olympiad Practice | Class 2 | Unit 6 of 21**

> **Parent's Note:** Encourage him to draw a simple line on paper and place names/letters on it in order as he reads each clue — this "line trick" solves almost every ranking question.

---

## 🎯 What You Will Learn

- Arranging people/things in order using clues (tallest to shortest, heaviest to lightest, first to last)
- Finding someone's **position** in a line (from the front, from the back, or from both!)
- The handy trick: **position from front + position from back − 1 = total in the line**

---

## 💡 Learn It First

**The Big Idea:** You're given clues comparing people two at a time. Line them up in order to answer the question.

```
Reema is taller than Simran.
Simran is taller than Anu.
```
Draw it as a line, tallest on top:
```
Reema   (tallest)
Simran
Anu     (shortest)
```

**Position trick:** If a child is 3rd from the front in a line of 7, their position from the back is:
```
7 − 3 + 1 = 5th from the back
```
*Why the "+1"?* The child gets counted once from the front AND once from the back — subtract 1 so we don't count that same child twice.

### 🧠 How to Solve — 3 Easy Steps
1. **Write down** each clue as an order (who is above/below whom).
2. **Combine** all the clues into ONE single line, top to bottom.
3. **Read off** the answer from your line.
