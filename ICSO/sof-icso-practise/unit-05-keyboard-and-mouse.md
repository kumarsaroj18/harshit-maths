## 🎯 What You Will Learn

- Important keyboard keys: **Space bar, Enter, Backspace, Shift, Caps Lock, Arrow keys**
- Mouse actions: **click, double-click, right-click, scroll, drag**
- Which key or mouse action to use for a given task

---

## 💡 Learn It First

**Keyboard keys:**
| Key | What it does |
|---|---|
| Space bar | Leaves a space between words (the longest key!) |
| Enter | Moves to a new line / confirms |
| Backspace | Erases the letter BEFORE the cursor |
| Shift | Types a CAPITAL letter while held down |
| Caps Lock | Locks typing to ALL CAPITAL letters |
| Arrow keys | Move the cursor up, down, left, right |

**Mouse actions:**
| Action | What it does |
|---|---|
| Click | Selects or presses something once |
| Double-click | Click twice quickly — opens a file or icon |
| Right-click | Opens a menu with more options |
| Scroll (wheel) | Moves the page up or down |
| Drag | Click, hold, and move something across the screen |

### 🧠 How to Solve — 3 Easy Steps
1. **Picture** what needs to happen (a space? a capital letter? opening a game?).
2. **Match** it to the ONE key or mouse action that does exactly that.
3. **Double-check**: keyboard keys are for typing; mouse actions are for pointing, clicking, and selecting.
