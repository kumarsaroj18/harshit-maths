## 🎯 What You Will Learn

- Spotting what **repeats** in a row of colours, shapes, or numbers
- Finding the **missing piece** — at the end OR in the middle
- Patterns that **grow** (more and more) or **shrink** (less and less)
- Patterns that **turn/rotate**
- Patterns hiding inside a **grid** (like a mini sudoku!)

---

## 💡 Learn It First

**1. Repeating patterns** — a small group of things repeats again and again.

```
🔴🔵🔴🔵🔴🔵 ...   ← "Red, Blue" repeats forever (this is an AB pattern)
🔴🔵🟡🔴🔵🟡 ...   ← "Red, Blue, Yellow" repeats (this is an ABC pattern)
🟢🔴🔴🟢🔴🔴 ...   ← "Green, Red, Red" repeats (this is an ABB pattern)
```

**2. Growing patterns** — the pattern adds one more thing each time.

```
●   ●●   ●●●   ●●●●   ...   ← one more circle every time!
```

**3. Rotating patterns** — a shape or arrow turns a little bit each time.

```
➡️  ⬇️  ⬅️  ⬆️  ➡️  ⬇️  ...   ← the arrow keeps turning the same way
```

**4. Grid patterns** — every row and every column uses the same shapes, just in a different order (like a puzzle!).

```
▲ ● ■
● ■ ▲
■ ▲ ●
```

### 🧠 How to Solve a Pattern Question — 3 Easy Steps

1. **Look** — what small group of things keeps repeating?
2. **Count** — how many items are in that group before it starts again?
3. **Place** — figure out where the blank falls in that repeating group.
