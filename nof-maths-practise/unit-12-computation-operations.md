## 🎯 What You Will Learn

- **Addition** with carrying (regrouping) — 2 and 3-digit numbers
- **Subtraction** with borrowing (regrouping)
- **Multiplication** as repeated addition (tables up to 5)
- **Division** as equal sharing
- Simple word problems using all four operations

---

## 💡 Learn It First

**Addition with carrying:**
```
   38
 + 47
 ----
  8 + 7 = 15 → write 5, carry 1
  3 + 4 + 1(carried) = 8
 ----
   85
```

**Subtraction with borrowing:**
```
   82
 - 35
 ----
  2 is smaller than 5, so borrow 1 ten: 12 − 5 = 7
  Now tens: 7 − 3 = 4
 ----
   47
```

**Multiplication** = repeated addition:
```
4 × 3  =  4 + 4 + 4  =  12
```

**Division** = equal sharing:
```
12 ÷ 3  →  share 12 into 3 equal groups  →  4 in each group
```

### 🧠 How to Solve — 3 Easy Steps
1. **Line up** the ones, tens, and hundreds columns carefully.
2. **Start from the ones column** — carry or borrow if needed.
3. For word problems: **decide the operation** first (add, subtract, multiply, or divide) before calculating.
