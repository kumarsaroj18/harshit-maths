# 🥤 Unit 15 — Capacity

**NOF Maths Olympiad Practice | Class 2 | Unit 15 of 21**

> **Parent's Note:** Use a measuring jug and a few bottles/cups at bath time or in the kitchen — capacity is easiest to learn by actually pouring water.

---

## 🎯 What You Will Learn

- Units of capacity: **millilitre (mL)** and **litre (L)**
- The conversion rule: **1 L = 1000 mL**
- Adding and subtracting capacities
- Comparing and ordering capacities

---

## 💡 Learn It First

```
1 litre (L)  =  1000 millilitres (mL)
```

**Converting litres to millilitres:** multiply by 1000
```
2 L = 2 × 1000 = 2000 mL
```

**Converting millilitres to litres:** divide by 1000 (works evenly for multiples of 1000)
```
4000 mL = 4000 ÷ 1000 = 4 L
```

**Adding/subtracting capacities** — keep the unit the same:
```
250 mL + 300 mL = 550 mL
1 L 200 mL  =  1200 mL   (1 L = 1000 mL, so 1000 + 200 = 1200)
```

### 🧠 How to Solve — 3 Easy Steps
1. **Check the units** — are both amounts in mL, or in L? Make them match first.
2. **Convert** using 1 L = 1000 mL if needed.
3. **Add, subtract, or compare** the numbers normally.
