# 🔗 Unit 5 — Analogy

**NOF Maths Olympiad Practice | Class 2 | Unit 5 of 21**

> **Parent's Note:** Read the first pair together and ask "How are these two connected?" out loud before looking at the options — naming the connection is the whole trick.

---

## 🎯 What You Will Learn

- Finding the **connection** (relationship) between a pair of things
- Applying the **same connection** to a new pair
- Common analogy types: baby-parent, part-whole, use/tool, category, opposite, number relation

---

## 💡 Learn It First

**The Big Idea:** Analogy questions give you a matched PAIR, then ask you to complete a SECOND pair using the SAME connection.

```
🐄 is to 🐮  as  🐕 is to  ___
(Cow)  (Calf)     (Dog)
```
Connection: **animal → its baby**. A dog's baby is a puppy, so the answer is 🐕‍🦺 (puppy)!

**Common connections to look for:**
| Connection type | Example |
|---|---|
| Animal → baby | Cow → Calf, Dog → Puppy |
| Part → whole | Wheel → Car, Page → Book |
| Tool → user | Pen → Writer, Needle → Tailor |
| Object → group | Apple → Fruit, Car → Vehicle |
| Opposite | Hot → Cold, Big → Small |
| Number pattern | 2 → 4 (double), 5 → 10 (double) |

### 🧠 How to Solve — 3 Easy Steps
1. **Name** the connection between the first pair in a full sentence: "A ___ is the baby of a ___."
2. **Use that exact sentence** with the new first word.
3. **Pick** the option that completes the sentence correctly.
