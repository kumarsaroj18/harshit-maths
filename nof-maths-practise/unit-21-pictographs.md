## 🎯 What You Will Learn

- Reading a **pictograph** (a chart made of pictures/icons)
- Understanding the **key** (what 1 icon stands for)
- Comparing categories: most, least, more than, fewer than
- Working with a **half icon** when the count is an odd number

---

## 💡 Learn It First

**A pictograph** uses pictures to show information. The **KEY** tells you what each picture is worth.

```
KEY: 🍎 = 1 student

Apple:   🍎🍎🍎🍎        → 4 students like apple
Grapes:  🍎🍎🍎🍎🍎      → 5 students like grapes
```

**When 1 icon = more than 1 unit:**
```
KEY: 📕 = 2 books

Riya:  📕📕📕   → 3 icons × 2 books = 6 books
```

**Half an icon** means half the value:
```
KEY: 📕 = 2 books
Half a 📕 = 1 book (half of 2)
```

### 🧠 How to Solve — 3 Easy Steps
1. **Read the key first** — always check what 1 icon is worth before answering anything.
2. **Count the icons** for each category.
3. **Multiply** (icons × key value) to get the real total, then add/subtract/compare as needed.
